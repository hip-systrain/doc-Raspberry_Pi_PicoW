VSCode は シリアルターミナルではない


ターミナル = 命令を出す端末のターミナル(= 送信する端末)
シリアルターミナル ≒ 接続した端末のターミナル(= 受信する端末)


- シリアルターミナルの一種であるTeratarmをインストール
- デバッグプローブ = 白いコード

USBとデバッグプローブ(UART)2種が必須

# USB

※PCに接続するためのUSBポートを1つ用意すること

USBの方はhello_usb.cを動かして、表示されることを確認

(Runを行ったあとにTeratarmのシリアルから確認できる)


# デバッグプローブ

※PCに接続するためのUSBポートを2つ用意すること

SWD規格 (Dから出ているケーブル)

ボードに「DEBAG」と印字されている直下に、
左から「赤-黒-黄」の順で接続する。


UART規格　(Uから出ているケーブル)

ボードに「LED」と印字されているさらに左側に
「1」「2」と数字が印字されている。
ボードに対して、上から順に「黄(ボードの1と印字されている箇所の左)-赤(ボードの2と印字されている箇所の左)-黒」の順で接続する。

ビルドまで実施した後に、Raspberry Pi Picoの拡張メニューから「Flash Project (SWD)」を選択する

デバッグプローブもhello_usb.cを動かして、表示されることを確認

(「Flash Project (SWD)」を行ったあとにTeratarmのシリアルから確認できる)
