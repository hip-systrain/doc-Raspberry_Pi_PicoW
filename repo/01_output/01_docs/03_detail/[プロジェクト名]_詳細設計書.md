# 3. データ設計

## 3.1. 定数定義
定数定義の詳細を次に示す。
#### 定数一覧
| 定数名       | 型    | 値    | 意味                                 | 定義箇所                 |
| ------------ | ----- | ----- | ------------------------------------ | ------------------------ |
| DISTANCE_MIN | short | 0     | 超音波センサーが測定できる最小の距離 | 超音波センサーモジュール |
| DISTANCE_MAX | short | 2,000 | 超音波センサーが測定できる最大の距離 | 超音波センサーモジュール |

## 3.2. enum定義
enum定義の詳細を次に示す。
#### read_sw_t
| 列挙子名   | 値  | 意味                    |
| ---------- | --- | ----------------------- |
| SWITCH_OFF | 0   | リードスイッチがON状態  |
| SWITCH_ON  | 1   | リードスイッチがOFF状態 |
#### wifi_stat_t
| 列挙子名       | 値             | 意味                |
| -------------- | -------------- | ------------------- |
| NOT_CONNECTED  | 0              | Wi-Fiが未接続状態   |
| CONNECTING     |                | Wi-Fiが接続中状態   |
| ・<br>・<br>・ | ・<br>・<br>・ | ・<br>・<br>・      |
| CONNECTED      |                | Wi-Fiが接続済み状態 |

## 3.3. 変数定義

| リードスイッチ状態 | read_sw_stat    | read_sw_t      | read_sw_t の列挙子          | 0              | リードスイッチのON/OFF状態を表す                       | リードスイッチモジュール内で保管 |
| 対物距離           | object_distance | short          | DISTANCE_MIN ~ DISTANCE_MAX | DISTANCE_MAX   | 超音波センサーで読み取った距離をミリメートル単位で表す | 超音波センサーモジュール内で保管 |
