## 4.3. 機能詳細
- 本機器センサー状態判別機能 <br>
リードSWおよび超音波センサーの入力を基に本機器がサーバーへ通知するセンサー状態を決定する。センサー状態はリードSW及び超音波センサーの入力値からそれぞれの条件でON/OFFの状態判定を行い、いずれかがONまたは両方がONとなれば本機器センサーの結果はONとなりそれ以外はOFFとなる。  
  

|リードSW状態| 超音波センサー状態 | 本機器センサー状態 |  
|:---:|:---:|:--:| 
|OFF| OFF|  OFF |
| <span style="color:red;">ON</span> | OFF|  <span style="color:red;">ON</span> |
| OFF | <span style="color:red;">ON</span>|  <span style="color:red;">ON</span> |
| <span style="color:red;">ON</span> | <span style="color:red;">ON</span>|  <span style="color:red;">ON</span> |

- - リードSW <br>
リードSWの状態はポートからの入力信号を直接取り込み、スイッチが押されている状態をON,離されている状態をOFFとする。  
チャタリングの対策として入力信号が切り替わったタイミングでの状態変化は行わず、入力信号の前回値と比較して信号が一致していれば状態を確定する。

|現在のリードSW状態|前回の信号| 現在の信号 |リードSW状態変化|  
|:---:|:---:|:--:|:--:| 
| OFF | OFF | OFF | OFF |
| OFF | ON | OFF | OFF |
| OFF | OFF | ON | OFF |
| OFF | ON | ON | OFF → ON |
| ON | OFF | OFF | ON → OFF |
| ON | ON | OFF | ON |
| ON | OFF | ON | ON |
| ON | ON | ON | ON |

- - 超音波センサー<br> 
超音波センサーの状態は測定した距離が所定の範囲内において閾値以下であればON,閾値より大きければOFFとなる。範囲外の値となる距離が測定された場合は測定エラーとし状態の切り替えは行わず現在の状態を維持する。  
　  
範囲を決める値は以下とする。  
測定最小値：測定した距離が範囲内に含まれる最小値  
測定最大値：測定した距離が範囲内に含まれる最大値  
判定閾値　：範囲内の値でON/OFFの区切りとなる閾値  

|現在センサー状態| 測定距離 | センサー状態変化 |  
|:---:|:---:|:--:| 
| OFF | 測定最小値未満 (測定エラー)         | OFF      |
| OFF | 測定閾値以上　判定閾値以下         | OFF → ON |
| OFF | 測定閾値より大きい　測定最大値以下 | OFF      |
| OFF | 測定最大値より大きい (測定エラー)   | OFF      |
| ON　| 測定最小値未満 (測定エラー)         | ON |
| ON  | 測定閾値以上　判定閾値以下         | ON |
| ON  | 測定閾値より大きい　測定最大値以下 | ON → OFF |
| ON  | 測定最大値より大きい (測定エラー) | ON |


- Wi-Fi接続チェック機能<br>
現在のWi-Fiの接続状況を確認し、未接続であれば接続要求を行う。  
また、接続状態として接続済み/接続試行中のどちらかの状態を持つ。  

|接続状況| 接続要求 | 接続状態 |  
|:---:|:---:|:--:| 
| 接続中 | 行わない | 接続済み |
| 未接続 | 行う | 接続試行中 |
| 接続待ち | 行わない | 接続試行中 |
