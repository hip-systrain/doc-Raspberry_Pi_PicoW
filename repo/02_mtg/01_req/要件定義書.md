# 1. はじめに
本書は、「Raspberry Pi Pico W/2W（以下「Pico」と記載） 開発手順書作成」の要件定義書である。参考資料を以下に示す。
 - [手順書テンプレート](https://docs.google.com/presentation/d/1Bl2NqJz9W8lAkm-M4A8aKznSpVRzpFoKyBHCuVhZBM0/edit?slide=id.p1#slide=id.p1)
 - [手順書作りの進め方](https://docs.google.com/presentation/d/1_b6zPOexN3ShQKko4xUrnjy8VZ3ExeQtu94jitT5fBY/edit?slide=id.p1#slide=id.p1)
 - [Pico microcontroller boards](https://www.raspberrypi.com/documentation/microcontrollers/pico-series.html)

# 2. プロジェクト概要
本プロジェクトは、Pico を用いた組み込み開発の手順書を作成するプロジェクトである。  
研修生は本手順書に従い、Pico を用いた組み込み開発を体験することで、開発の一例を理解できる。

# 3. 要件
下記の3資料に則り、読み手・書き手がともに迷わず運用できる手順書を作成する。
<br>・[オリエンテーション資料](https://docs.google.com/presentation/d/176VfFL6jnZMZvnlcnzQr2OYsId6LLqgdQosq3g9RXWk/edit?slide=id.p1#slide=id.p1)
<br>・[手順書づくりの進め方_Pico 編](https://docs.google.com/presentation/d/1_b6zPOexN3ShQKko4xUrnjy8VZ3ExeQtu94jitT5fBY/edit?slide=id.p1#slide=id.p1)
<br>・[手順書テンプレート紹介資料](https://docs.google.com/presentation/d/1Bl2NqJz9W8lAkm-M4A8aKznSpVRzpFoKyBHCuVhZBM0/edit?slide=id.p1#slide=id.p1)

また、テンプレートに則り以下の章構成で手順書を作成する。
```txt
0.概要
    0.1 この手順書でできること
    0.2 必要な機材
    0.3 前提知識・事前準備
1. 開発環境構築
    1.1 ツールのインストール
    1.2 ドライバのインストール
    1.3 インストールできたことの確認
2. シリアルターミナルの使い方
    2.1 使用するツールと接続方法
    2.2 通信設定(ポート、ボーレートなど)
    2.3 動作確認
3. プロジェクト作成
    3.1 新規プロジェクトの作成
    3.2 プロジェクトの構成(フォルダ・ファイルの役割)
4. コーディング・ビルド・書込み(RTOSなし)
    4.1 題材1:LED点滅
    4.2 題材2:ボタン入力
    4.3 題材3:UART出力
    4.4 題材4:タイマ割込み
5. コーディング・ビルド・書込み(FreeRTOS)
    5.1 FreeRTOSの導入・設定
    5.2 題材5:複数タスク
    5.3 題材6:タスク間通信
6. デバッグ
    6.1 デバッガの接続(配線図・写真)
    6.2 デバッグの開始
    6.3 ブレークポイント・ステップ実行
    6.4 変数・メモリ・レジスタの確認
7. トラブルシューティング
8. 参考資料
9. MicroPython
    9.1 準備・開発環境構築
    9.2 基本操作
    9.3 題材1:LED点滅
    9.4 題材2:ボタン入力
    9.5 題材3:UART出力
    9.6 題材4:タイマ割込み
    9.7 デバッグ
```
