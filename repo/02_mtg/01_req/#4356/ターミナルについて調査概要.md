## vscodeのターミナルとシリアルターミナルの違い
### vscodeのターミナル
vscodeのターミナルは、コマンドラインターミナルと呼ばれ、コマンド入力を介して入出力を行う  
### シリアルターミナル  
シリアルターミナルとは、PCとマイコンなどの電子機器をシリアル通信で接続し、文字列の送受信を行うためのソフトウェア  

#### それぞれの比較

| 比較項目     | vscodeターミナル | シリアルターミナル |
| -------- | ------- | --------- |
| 主な用途     | コマンド実行  | シリアル通信    |
| 通信相手     | OS・シェル  | マイコン・電子機器 |
| COMポート指定 | 通常不要    | 必要        |
| ボーレート設定  | 通常不要    | 必要        |
| データ送受信   | シェル経由   | シリアル通信経由  |

## VScodeでシリアル通信を行う方法  
VSCodeでは通常シリアル通信はできないが、拡張機能を利用して、エディタ内にシリアルターミナルを表示することが出来る。

例えば、以下のような拡張がある。
- Serial Monitor：シリアルポートの接続や送受信を行う拡張機能
- PlatformIO：組み込み開発環境。シリアルモニター機能も備える
