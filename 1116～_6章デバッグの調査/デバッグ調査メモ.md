
# 配線 デバッグプローブと Pico のつなぎ方(写真か図で)


## デバッグプローブ

SWD規格 (Dから出ているケーブル)

ボードに「DEBAG」と印字されている直下に、
左から「赤-黒-黄」の順で接続する。

UART規格　(Uから出ているケーブル)

ボードに「LED」と印字されているさらに左側に
「1」「2」と数字が印字されている。
ボードに対して、上から順に「黄(ボードの1と印字されている箇所の左)-赤(ボードの2と印字されている箇所の左)-黒」の順で接続する。

※前提条件としてUSBポートが2か所必要


# 開始 VS Code からデバッグを始める方法

1. 拡張機能「Raspberry Pi Pico」を選択する
2. 「Debug Project」を選択する
3. 上の欄にdebagと入力されて「Pico Debug」を選択できることを確認する
